# Sandpoint Chronicles

Welcome, heroes of Sandpoint! This is **our shared campaign wiki** — anyone in the party can add notes, theories, NPC pages, session recaps, whatever helps us remember what in the Abyss is going on.

## How it works

- Click **✎ Edit This Page** on any page to change it.
- Click **+ New Page** in the sidebar to start a fresh one, or hover over a folder and click **+ page** to add one there.
- Click **+ New Folder** (or a folder's **+ 📁** button) to organize pages into folders.
- To save, enter **your name** and the **table password** (ask the GM). Your browser remembers both after the first time.
- Link between pages by writing `[[Page Name]]` — a red link means the page doesn't exist yet, and clicking it lets you create it (in the same folder as the page you're on).
